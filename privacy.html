Maxfiylik Siyosati

Oxirgi yangilanish: 9 Aprel 2026

Assistly sizning maxfiyligingizni hurmat qiladi. Ushbu siyosat platformamizda to'planadigan ma'lumotlar va ulardan foydalanish tartibi haqida ma'lumot beradi.

1. To'planadigan ma'lumotlar

Biz quyidagi ma'lumotlarni to'playmiz:

  • Hisob ma'lumotlari: ism, email, telefon raqam
  • Biznes ma'lumotlari: kompaniya nomi, soha, veb-sayt
  • Foydalanish ma'lumotlari: xabarlar, suhbatlar, analitika
  • Texnik ma'lumotlar: IP manzil, brauzer turi, qurilma ma'lumotlari

2. Ma'lumotlardan foydalanish

To'plangan ma'lumotlar quyidagi maqsadlarda ishlatiladi:

  • Assistly xizmatlarini taqdim etish va yaxshilash
  • Texnik yordam ko'rsatish
  • Xavfsizlikni ta'minlash
  • Platforma faoliyatini tahlil qilish
  • Qonuniy majburiyatlarni bajarish

3. Ma'lumotlarni saqlash

Sizning ma'lumotlaringiz xavfsiz serverlarda saqlanadi. Biz sanoat standartlariga mos xavfsizlik choralarini qo'llaymiz: SSL shifrlash, parollar xeshlash (bcrypt), ma'lumotlar bazasi xavfsizligi.

4. Uchinchi tomon xizmatlar

Assistly quyidagi uchinchi tomon xizmatlaridan foydalanadi:

  • Telegram API — bot integratsiyasi uchun
  • Meta (Instagram) API — Instagram DM uchun
  • OpenAI API — AI javoblar uchun

Bu xizmatlar o'zlarining maxfiylik siyosatiga ega. Biz foydalanuvchi ma'lumotlarini ularning roziligisiz uchinchi tomonlarga sotmaymiz.

5. Cookie fayllari

Biz autentifikatsiya va foydalanuvchi tajribasini yaxshilash uchun cookie fayllaridan foydalanamiz. Brauzer sozlamalarida cookielarni o'chirib qo'yishingiz mumkin, lekin bu ba'zi funksiyalarga ta'sir qilishi mumkin.

6. Foydalanuvchi huquqlari

Siz quyidagi huquqlarga egasiz:

  • Ma'lumotlaringizga kirish va ko'rish
  • Ma'lumotlaringizni yangilash yoki to'g'rilash
  • Hisobingizni va ma'lumotlaringizni o'chirish
  • Ma'lumotlaringizni eksport qilish

7. Ma'lumotlarni o'chirish

Hisobingizni o'chirmoqchi bo'lsangiz, info@assistly.uz ga murojaat qiling. Barcha ma'lumotlaringiz 30 kun ichida o'chiriladi.

8. Bolalar maxfiyligi

Assistly 16 yoshdan kichik foydalanuvchilar uchun mo'ljallanmagan. Biz ataylab 16 yoshdan kichik shaxslardan ma'lumot to'plamaymiz.

9. Siyosat o'zgarishlari

Ushbu siyosat vaqti-vaqti bilan yangilanishi mumkin. Muhim o'zgarishlar haqida email orqali xabar beramiz.

Assistly уважает вашу конфиденциальность. Данная политика описывает, какие данные мы собираем и как их используем.

Мы собираем следующие данные:

  • Данные аккаунта: имя, email, номер телефона
  • Данные бизнеса: название компании, отрасль, веб-сайт
  • Данные использования: сообщения, разговоры, аналитика
  • Технические данные: IP-адрес, тип браузера, данные устройства

2. Использование данных

Собранные данные используются для:

  • Предоставления и улучшения услуг Assistly
  • Технической поддержки
  • Обеспечения безопасности
  • Анализа работы платформы
  • Соблюдения законодательных требований

3. Хранение данных

Ваши данные хранятся на защищённых серверах. Мы применяем отраслевые стандарты безопасности: SSL-шифрование, хеширование паролей (bcrypt), защита базы данных.

4. Сторонние сервисы

Assistly использует следующие сторонние сервисы:

  • Telegram API — для интеграции с ботом
  • Meta (Instagram) API — для Instagram DM
  • OpenAI API — для AI-ответов

Эти сервисы имеют собственную политику конфиденциальности. Мы не продаём данные пользователей третьим лицам без их согласия.

5. Файлы cookie

Мы используем cookie для аутентификации и улучшения пользовательского опыта. Вы можете отключить cookies в настройках браузера, однако это может повлиять на некоторые функции.

6. Права пользователей

Вы имеете право:

  • Просматривать свои данные
  • Обновлять или исправлять данные
  • Удалять аккаунт и данные
  • Экспортировать данные

7. Удаление данных

Для удаления аккаунта обратитесь на info@assistly.uz. Все данные будут удалены в течение 30 дней.

8. Конфиденциальность детей

Assistly не предназначен для пользователей младше 16 лет. Мы не собираем намеренно данные лиц младше 16 лет.
